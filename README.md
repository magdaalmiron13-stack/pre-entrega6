
# Mi Recetario

Sitio web de recetas desarrollado como proyecto del curso de Desarrollo Web.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Bootstrap 5
- Git y GitHub

## Secciones

- Inicio
- Recetas dulces
- Recetas saladas
- Básicos de cocina
- Recetas saludables

## Funcionalidades

- Diseño responsive para celulares y computadoras.
- Menú de navegación adaptable.
- Galería de imágenes con carousel de Bootstrap.
- Acordeones interactivos para consultar procedimientos.
- Enlaces entre recetas.
